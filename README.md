# Codeforces Heatmap

Codeforces Heatmap is a Dank Material Shell plugin that visualizes your Codeforces problem-solving activity as a contribution-style heatmap.

## Preview

![Codeforces Heatmap preview](CodeForcesHeatMap/Pasted%20image.png)

## Features

- Displays a color-coded activity heatmap for your Codeforces submissions
- Shows your total solved count and a daily summary
- Fetches your Codeforces profile photo when available, with a local icon fallback
- Integrates with Dank Material Shell as a widget plugin

## Requirements

- `bash`
- `curl`
- `jq`
- `notify-send`
- `xdg-open`

## Installation

1. Clone or copy this repository.
2. Ensure the `CodeForcesHeatMap/` folder is available to Dank Material Shell.
3. Register the plugin using the repository metadata in `plugins/codeforcesheatmap.json`.
4. Set your Codeforces handle in the plugin settings.
